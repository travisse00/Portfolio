# Travis Portfolio

A proper multi-page React portfolio application built with Vite.

## Pages

- `/` - Home
- `/about` - About
- `/projects` - Projects
- `/projects/e-voting` - E-Voting case study
- `/projects/expense-tracker` - Expense Tracker case study
- `/projects/library-management` - Library Management case study
- `/skills` - Skills
- `/experience` - Experience
- `/contact` - Contact
- `*` - Not found

## Stack

- React
- React Router
- Vite
- Lucide React
- Plain CSS

No CSS gradients are used.

## Run locally

```bash
npm install
npm run dev
```

## Before deploying

Update the placeholder GitHub, LinkedIn, email, and project repository URLs in:

`src/data/projects.js`

The live E-Voting URL is already included.

## Build

```bash
npm run build
npm run preview
```
